# 芒果灵创节点式画布 · React V1.9.9

用于产品评审和研发对齐的高保真交互原型。V1.9.9 将文字节点全屏态改为无可见标题的居中高面板，并把图片 / 视频全屏预览扩大到接近视口边界；V1.9.8 的图片编辑闭环、芒果橙色界面、左上角背景色面板与统一资产入口继续保留。图片 / 视频 Prompt 生成、合规审核、智能选择、播放列表合并和媒体处理仍为确定性本地 Mock，不连接 TapNow 或后端模型。

## 在线原型与部署

本仓库仅承载交互原型，不能作为生产前端工程直接复用。部署为静态网站时使用：

- Build Command：`pnpm build`
- Output Directory：`dist`
- Node 版本：20 或更高

每次合并到 `main` 后，由部署平台自动更新研发访问链接；功能分支只用于预览和验收。

## V1.9.6 图片编辑器真实编辑与状态加固

- 保存数据升级为来源感知的 Fabric V2 文档，保留画板、对象、来源节点与真实渲染预览，并兼容旧版编辑数据迁移；保存前选择 1× / 2× / 3×，存在未保存更改时关闭会明确询问保存、放弃或取消。
- 裁剪作为封闭事务处理，临时蒙版不会写入结果；橡皮擦笔划会序列化并在裁剪、保存或导出前完成材质化；Pen Tool 重编辑保留原对象 ID、图层顺序、样式和变换。
- 历史切换、保存、生成、导出和异步抠图期间统一锁定冲突操作；多选不显示单对象属性栏，普通滚轮保留原生行为，Ctrl / Cmd + 滚轮缩放，Space 提供临时抓手。
- Prompt 不属于画布保存快照，也不触发未保存状态；生成会先保存当前画面，再按参数创建可追溯的图片 / 视频节点与任务，但结果仍为确定性本地 Mock。
- 支持在浏览器本地导出 PNG、JPEG 和分层 PSD；位图与保存回写使用当前画布真实渲染结果，不再只导出 JSON 编辑数据。
